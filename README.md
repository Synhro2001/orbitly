# Orbitly

Мессенджер для близких друзей: ты — планета, друзья вращаются вокруг тебя.
Чем ближе общение, тем ближе орбита.

Сейчас это **вёрстка на моковых данных**: бэкенда, авторизации и настоящей
камеры нет. Данные живут в памяти и сбрасываются при перезапуске, поэтому
каждый запуск начинается с создания планеты.

## Чем отличается от Snapchat

- **Тень.** Можно уйти в тень на 1 день, 3 дня или неделю (экзамены, отпуск).
  Серии со всеми замирают (🌘), а после возвращения у друзей есть целые сутки,
  чтобы продолжить. Это ответ на главную жалобу на серии в Snapchat: их
  поддерживают из тревоги, даже когда нет сил.
- **«С чего начать?»** Если друг отдаляется или серия дала трещину, над полем
  ввода появляются первые фразы. Подсказка подставляется в поле, а не
  отправляется сама — её можно дописать.
- **Капсула времени.** Послание, которое друг прочитает завтра, через неделю,
  месяц или год. До срока у получателя видна только запечатанная капсула.

Логика тени — в `EvaluateStreak` (`core/domain/usecases`), открытие капсулы —
`CapsuleMessage.isOpenAt` (`features/chat/domain`). Подсказки решает сервер:
в mock их получают друзья из списка отдаляющихся и те, с кем не общались сутки.

## Запуск

Нужен Flutter stable (проверено на 3.47.5 / Dart 3.13.4).

```bash
flutter pub get
flutter run -d edge        # веб (или -d chrome, если Chrome установлен)
flutter run                # Android-эмулятор
flutter test
flutter analyze
```

### Генерация кода

Модели (freezed/json), провайдеры (riverpod_generator) и строки (ARB) —
генерируемый код, он закоммичен. После изменения моделей или провайдеров:

```bash
dart run build_runner build
```

**Windows и кириллица в пути.** `build_runner` не работает, если в пути к
проекту есть не-ASCII символы (например, «Рабочий стол»): падает с
`package_config.json did not contain its own root package`. Обходной путь —
временная буква диска:

```bash
subst O: "C:\путь\к\orbitly"
cd /d O:\
dart run build_runner build
subst O: /d
```

## Структура

```
lib/
  main.dart
  app/            App, роутер, нижняя навигация, di.dart — провайдеры репозиториев
  core/
    domain/       общие сущности (Friend, PlanetAppearance, Streak, Mood, Award)
                  и EvaluateStreak
    data/         общие модели freezed/json, mock/mock_store.dart — фейковый бэкенд
    theme/        токены: цвета, отступы, размеры, длительности, тема
    widgets/      PlanetView, звёздный фон, бейдж серии, просмотр снапа
    planet_render/ PlanetPainter, детерминированный random, кэш ui.Image
    utils/        clock, l10n-расширения
  features/
    system/       главный экран: орбиты, моменты, CalculateOrbitRadius
    chat/         список чатов и чат со снапами
    camera/       интерфейс камеры (заглушка)
    planet/       моя планета: уровень, XP, серия, награды, настроение
    friends/      поиск, заявки, ссылка-приглашение
    report/       отчёт недели
    onboarding/   создание планеты
  l10n/app_ru.arb все строки интерфейса
test/             unit-тесты domain, widget-тесты системы и чата
```

В фиче: `domain/` (чистый Dart: сущности, интерфейс репозитория, use cases),
`data/` (модели, мапперы, mock-репозиторий), `presentation/` (экраны,
виджеты, контроллеры Riverpod). У `camera` и `onboarding` своих данных нет,
поэтому только `presentation/`; онбординг сохраняет планету через репозиторий
фичи `planet`.

## Решения

- **Одна точка подмены.** UI видит только интерфейсы репозиториев через
  провайдеры из `app/di.dart`. Для бэкенда заменить `Mock*Repository` на
  настоящие реализации там же.
- **Mock-данные идут через JSON.** `MockStore` хранит данные в виде JSON
  в snake_case, как их отдал бы Supabase. Репозитории проходят тот же путь
  JSON → модель → сущность, что и с настоящим сервером. Все mock-репозитории
  делят один `MockStore`, поэтому экраны согласованы.
- **Use cases только там, где есть логика:** `CalculateOrbitRadius` и
  `EvaluateStreak`. Простое чтение и запись контроллеры делают через
  интерфейс репозитория, без пустых обёрток.
- **Серия:** меньше 24 ч с последнего обмена — активна, 24–48 ч — трещина,
  дальше — сгорела.
- **Планеты** рисуются `CustomPainter` по seed (свой xorshift, чтобы веб и
  Android совпадали). Готовые картинки кэшируются в `ui.Image` и показываются
  через `RepaintBoundary`. Превью в онбординге рисуется вживую.
- **Система:** планеты двигает `Flow` без перестройки виджетов, они
  сортируются по глубине, комета летит к друзьям с непрочитанным. Размеры и
  наклон орбит подстраиваются под экран. При «уменьшить движение» система
  стоит.
- **Камера** открывается свайпом влево от правого края главного экрана
  (узкая зона, чтобы не мешать перетаскиванию системы) или кнопкой.
- **Шрифты:** Golos Text и Unbounded (OFL), лежат в `assets/fonts`.
- **Анализ:** `very_good_analysis` без двух правил. `public_member_api_docs`
  отключено, потому что это приложение, а не пакет. Правило про новый
  синтаксис конструкторов отключено, потому что freezed использует
  классический. `riverpod_lint`/`custom_lint` не подключены: с ними версии
  freezed и json_serializable откатываются на старые.
